Der Haken, ehrlich markiert: die orange „global“-Zeilen gelten heute für den GESAMTEN Workspace, nicht pro Repo — es gibt bis jetzt keinen Repo-Datensatz (keine repos-Tabelle, kein register_repo; ein Repo ist nur ein Pfad-String auf einer Karte). Zwei Vorlagen nebeneinander würden sich gegenseitig überschreiben.

Entschieden (Owner, 2026-08-30): pro Repo — jedes Repo ist ein eigenes Projekt mit eigenem Git. Phase-2-Karte 1 macht den bestehenden Projekt-Datensatz zum Repo-Datensatz (statt einer zweiten Registratur). Danach sind diese Zeilen wirklich pro Repo. Ebenfalls entschieden: die Vorlage setzt den Startwert, der Autonomie-Regler darf ihn später ändern — die Karte markiert das dann sichtbar als „vom Standard abgewichen“.
